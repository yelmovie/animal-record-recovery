# 동물기록 복구작전 · 하루와 모리의 자연 탐험 (0.5.0)

## 2026-10-19 창작 작업실·활동 UX 개선

주민의 부탁은 탐험 뒤 도착하는 편지와 한 번의 답장으로 이어진다. 관찰핀 없이도 특징을 기록할 수 있고, 움직임 기록은 다음 행동과 완료 상태를 표시한다. 장소별 주민·탐사 도구·복구 사진을 새 이미지로 연결했다.

공방은 동물 특징 체험 → 모양 비교 → 자유 발명 그림 → 작품 소개로 진행한다. 원형 색상판·밝기·펜/연필/마커·굵기 슬라이더를 제공하며, 그림과 소개를 PNG로 저장하고 전시할 수 있다. 기존 별과 완료 기록은 유지한다. 아래 0.5 설명 중 두 번째 정해진 발명과 반복 재시험은 이전 저장 기록의 흐름이다.

[창작 작업실과 128개 테스트 검증](docs/creative-studio.md) · [주민·도구 이미지 작업 기록](docs/visual-polish-v2.md)

배포는 `npm ci` 후 `npm run deploy`로 실행한다. `wrangler.jsonc`의 기존 `animal-record-recovery` 프로젝트에 `dist/` 정적 파일을 올린다. 테스트 캡처와 생성 원본을 담은 `output/`은 Git과 배포에서 제외한다.

초등 과학 ‘동물의 생활’ 학습 게임. 사람 탐험가 하루가 이미지 지도에 그려진 길을 따라 이동하고, 너구리 모리가 따라다니며 관찰과 기록을 돕는다. 분류 장소는 탐색 2개, 다른 장소는 탐색 4개 → 본·응용 의뢰 2개 → 선택 도전 1개로 이어지고, 발견한 사실을 주민의 부탁에 사용해 자연 기록 전시관을 다시 연다.

## 0.5 전시관 확장

탐색 18개에 의뢰 10개와 선택 도전 5개를 추가했다. 설명판 수리·새 동물 분류·생태 방송·기록 반환·손님 조건에 맞춘 발명 재시험을 제공한다. 새 탐험은 의뢰 2개까지 마쳐야 장소와 다음 길이 열린다. 기존에 받은 도구와 완료 장소는 유지한다. 별은 최대 18개이고 의뢰는 전시물·배지로 남는다.

[설계](docs/MUSEUM-PLAN-20261018.md) · [110개 테스트 및 최종 검증](docs/reviews/FINAL-CHECK-20261018.md) · [새 메인 이미지 프롬프트](docs/MUSEUM-ASSET-PROMPT-20261018.json)

## 실행

Node.js 20 이상, 외부 패키지 설치나 API 키 불필요.

```sh
npm start
npm run check
npm test
npm run build
npm run preview
```

개발 주소는 `http://127.0.0.1:4173/`. `npm run preview`는 `dist/` 배포본을 같은 기본 포트로 제공한다. 개발 서버가 열려 있으면 별도 포트를 지정한다. PowerShell 예: `$env:PORT='4174'; npm run preview`.

## 18개 탐구 활동

| 장 | 첫 탐구 | 다음 탐구 |
|---|---|---|
| 관찰의 숲 | 확대 렌즈로 개구리·게 6곳 관찰, 공통점·차이 비교 | 오리·토끼 6곳 관찰, 다른 특징 비교 |
| 분류의 정원 | 6종을 날개 O/X로 분류 | 모두 같은 결과를 얻을 수 있는 기준으로 고치기 |
| 생태의 물가 | 3환경 발견, 움직임 재생·정지·장면 기록, 개구리 생활 연결 | 새 동물의 움직임 기록, 게 생활 연결 |
| 동물 찾기 안내소 | 부분 그림의 단서 수집→후보 줄이기→오리의 환경·생활 | 새 단서 수집→후보 줄이기→토끼의 환경·생활 |
| 발명의 공방 | 물갈퀴 관찰→오리발 설계→폭 변경·예상·두 시험 비교·설명 | 등딱지 또는 털을 활용한 발명→덮개 범위 또는 겹 변경·시험·설명 |

첫 발명은 물갈퀴를 이용한 오리발, 두 번째는 안전모 또는 방한 외투를 만든다. 같은 조건에서 한 부분만 바꾸고, 서로 다른 두 설정을 시험하여 비교한다. 예상이 틀렸다고 실패하지 않으며 관찰·예상·시험·비교·알게 된 점을 남겨야 한다. 시험은 정성적인 설명 모형이며 실제 물리 성능·안전성 측정이 아니다. 펜 스케치와 글의 내용은 자동 채점하지 않는다. 친구와 설명·질문·의견 교환을 함께 운영한다.

## 역할과 보상

- 하루: 학생을 대신하는 탐험가. 지도 길의 실제 경유점을 따라 이동한다.
- 모리: 하루를 따라가는 기록 보조원. 실제 수집 기록을 수첩과 도구에 보여 준다.
- 검증한 활동당 탐험 별 1개, 최대 18개. 반복 클릭이나 속도로 추가 점수를 얻지 않는다.
- 장소를 복구하면 관찰 렌즈·분류 나침반·서식지 수첩·특징 스캐너·발명가 배지를 받는다.
- 도구를 가방이나 활동 화면에서 꺼내 다음 탐구에 사용한다. 모은 동물 카드 9종과 완료한 발명이 최종 결과에 반영된다.

## 교육과정과 화면 검증

[4과02-01] 관찰·특징 분류, [4과02-02] 환경과 생김새·생활 관계, [4과02-03] 특징을 활용한 생활용품 설계·협력적 소통과 연결했다. 협력적 소통은 실제 교실 대화와 교사 관찰을 함께 확인한다. 상세 근거와 화면별 검증 범위는 [태블릿 탐구 QA](docs/reviews/TABLET-INQUIRY-QA-20261016.md)를 참고한다.

## 저장과 이전 기록

현재 브라우저 LocalStorage에 자동 저장한다. 주소·포트·브라우저가 다르면 기록도 분리된다. 학생 이름·학번을 수집하거나 기록을 서버로 보내지 않는다.

저장 형식 v4는 v3 기록을 이관하고 작품별 초안과 완료본을 분리한다. 분류 반복 축소로 없어진 두 활동을 제외한 기존 별·완료 기록은 유지한다. 기존 완료 기록을 취소하거나 새 활동을 했다고 가정하지 않는다.

0.2 버전 기록은 보관하고 확인 가능한 첫 관찰·분류·환경 탐구만 이관한다. 새로 늘어난 활동과 바뀐 4장은 직접 해야 한다. 이전에 열렸던 장소의 입장 권한을 유지한다. 전체를 처음부터 보려면 탐험 가방 → 탐험 기록 초기화에서 확인 후 시작한다.

통과한 동물 안내 카드와 발명은 별도 제출 기록으로 보관한다. 다시 탐험하며 초안을 바꿔도 미검증 초안으로 최종 결과가 덮어써지지 않는다. 새 의뢰의 전시 기록은 최초 검증 제출본을 보존하며, 재풀이로 중복 보상을 주지 않는다.

## 빌드와 전달

`npm run build`는 실행에 필요한 파일만 `dist/`에 복사하고 CSS 이미지 경로를 확인한다. 이전 빌드 매니페스트에 기록된 미사용 실행 파일만 정리하며 원본·사용자 파일을 삭제하지 않는다. PNG 원본·테스트·문서는 배포 ZIP에서 제외한다. 정적 호스팅에 `dist/`의 내용만 올린다.

기존 0.4 버전은 Cloudflare에 배포되어 있고, 이번 0.5 변경은 로컬 구현·검증·배포 파일 준비까지 수행했다. 실제 교실 기기·학생 사용·교사 내용 검수는 별도 확인 사항이다. 기존 로컬 three.js·GLB 표본·글꼴은 유지하며 학생 계정이나 외부 백엔드를 추가하지 않았다. 이미지 생성 고지와 제공 자료 출처는 설정과 `assets/CREDITS.md`에서 확인할 수 있다.

## 2026-10-18 영상·UX 검증

동물 움직임 영상 8종(낙타·펭귄은 선택 관찰), 인트로·아웃트로 각 24초를 포함한다. 작품별 초안·완료 기록·시험 이력을 분리하고 실제 TXT 다운로드를 검증했다. 현재 배포본은 130파일, 113.48MiB이며 운영 배포는 하지 않았다. 남은 가독성·실기기·권리·배포 검증과 항목별 점수는 `docs/reviews/FINAL-CHECK-20261018.md`에 있다.
