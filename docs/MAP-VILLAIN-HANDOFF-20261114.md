# 02 동물기록 복구작전 · 지도 악당 연계 계획

2026-11-14 디자인 시안과 후속 연출 계획. 아래 동작·대사·효과음은 시안에 적은 제안이다.

2026-11-15 확인: 장소 완료 뒤 지도에 악당이 등장하고, 공격 3회로 퇴장한다. 장소별 대사와 소품, 스프라이트, 멀리서 공격을 누르면 다가가는 동작이 구현되어 있다. [운영 사이트](https://animal-record-recovery.yelsam.workers.dev/)의 확인 커밋은 [`5bc4cb1`](https://github.com/yelmovie/animal-record-recovery/commit/5bc4cb11d0a88e9cc82725976a99a347d5d2dea4)이다. 시안 이미지와 여러 프로젝트의 합성본은 별도의 작업 공간에 보관했다.

## 외형과 등장

**가짜 발자국 도장꾼 / 보라 가면, 세 갈래 붉은 도장과 큰 기록장.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

하루·모리 각각의 지도 원본을 참조. 실제 동물은 악당이나 타격 대상으로 쓰지 않는다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 관찰의 숲 | 기록장에 가짜 발자국을 꾹 찍기 | “이 발자국, 내가 방금 만들었지!” |
| 분류의 정원 | 두 분류 표찰을 빠르게 바꿔 걸기 | “이름표만 바꾸면 모르겠지?” |
| 생태의 물가 | 동물 이동 기록 한 장을 뒤집기 | “아까 기록은 이쪽이었나?” |
| 동물 찾기 안내소 | 관찰 사진을 가면 뒤에 숨기기 | “이 사진은 내가 잠깐 빌릴게!” |
| 발명의 공방 | 오리발 설계 종이를 둘둘 말아 낚아채기 | “설계도는 내가 먼저 봐야지!” |

상황 대사 예시:

- 접근: “이 발자국, 진짜 같지?” / “그 기록장은 내 거야!”
- 1·2타: “앗, 도장이 비뚤어졌어!” / “가면이 자꾸 내려와!”
- 퇴장: “가짜 기록이 들켰네!” / “가면은 내가 챙겨 갈래!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 붉은 도장 자국이 톡 번짐 |
| 2타 · 더 큰 반동 | 종잇장 두 장이 좌우로 젖혀짐 |
| 3타 · 마무리와 퇴장 | 가면과 기록장 사이로 종이 조각이 접히며 악당이 달아남 |
| 주인공 접촉 | 하루는 수첩을 가슴 쪽으로 끌어안고 옆걸음 |
| 보조 캐릭터 접촉 | 모리는 기록 도구를 붙들고 뒤로 짧게 튐 |
| 악당의 접촉 공격 동작 | 도장을 이마 높이로 들었다가 허공에 ‘콕’. 붉은 도장 점은 닿은 방향에만 짧게 남김. |
| 타격·퇴장 효과음의 차이 | 콩 → 바스락 → 사락 |
| 접촉 효과음 모티프 | ‘툭, 바스락’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

가면과 몸은 방향을 바꾸되 기록장 속 가짜 발자국과 도장이 찍히는 위치는 그대로 둔다. 모리만 닿았을 때는 도장 손과 피격 방향을 모리 쪽에 맞춘다.

## 연출을 다시 손볼 때

1. [지도 연결](../src/village-encounters.js), [등장·타격·대사](../src/map-encounters.js), [공격 버튼](../src/map-attack-control.js), [악당 스프라이트](../assets/village/map-villain-right-v2.webp)에서 현재 동작을 확인한다.
2. 장소별 소품 동작이나 접촉 전조·피격·퇴장 프레임을 추가한다면 실제 지도 크기에서 알아볼 수 있는지 먼저 확인한다. 원안의 하루·모리 피격은 각각 4~6프레임이다.
3. 연출을 바꿀 때 기존 이동, 화면 전환, 복구 상태, 학습 완료와 다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.
