### 기준 밖이라 제안만 남긴 것

- **1장 비교 화면 구조 변경**: 지금은 동물 둘 + 질문 카드가 가로 한 줄이라, 사진을 더 키우면 질문 카드가 좁아진다. 높이 70%를 채우려면 "동물 사진 위 · 질문 카드 아래 가로 띠"로 배치를 바꿔야 한다. 배치 구조를 바꾸는 큰 수정이라 이번에는 하지 않았다(공통 기준 3절 4번).

## 3. 중복 조작 버튼 전수 점검

방법: 위 20개 화면 × 3 뷰포트에서 보이는 버튼·링크·`[data-action]`을 JS로 모두 뽑아(`before-v1/run.log`의 `ctrls:` 줄) 같은 일을 하는 것끼리 묶었다. 그 뒤 새 기록으로 홈부터 인증서까지 실제 클릭 완주 봇(`play-all.mjs`)으로 진행이 막히지 않는지 확인했다.

| # | 화면 | 중복 | 처리 | 진행 경로 확인 |
|---|---|---|---|---|
| 1 | 1장 관찰 | 기록 카드의 「두 동물 비교하기 →」와 아래 「다음으로 →」가 같은 `advance` | 다시 볼 때(활동이 이미 기록돼 아래 주 버튼이 있을 때) 카드 쪽을 숨김. 처음 할 때는 아래 주 버튼이 아직 없어 카드 버튼이 유일한 길이므로 그대로 둠 | 첫 진행은 자동 이어가기 + 카드 버튼, 다시 볼 때는 아래 주 버튼 |
| 2 | 3장 이어달리기 완주 | 완주 판의 「다음으로 →」(진한 주 버튼)와 아래 「탐구 마치기 →」 | 1번과 같은 규칙: 다시 볼 때 판 쪽을 숨김 | 첫 완주는 판 버튼이 유일한 길(봇에서 아래 주 버튼 없음 확인) |
| 3 | 주민 부탁·마지막 도전 | 카드 번호 칩(1~5) 앞의 「←」(이전 카드) — 칩으로 어느 카드든 바로 가고, 모양이 왼쪽 위 「뒤로」와 같아 헷갈림 | 「←」 삭제(로직 `request-card`는 칩이 그대로 씀) | 칩으로 모든 카드 이동 가능 |
| 4 | 전시관(5곳 완료) | 위 제목 옆 「발명과 탐험 인증서」와 오른쪽 아래 「탐험 인증서 보기 →」가 같은 `ending` | 위쪽 삭제, 아래 주 버튼 하나만 | 아래 주 버튼으로 인증서 진입(봇 완주) |

검토했지만 유지한 것(같은 일을 하지 않거나, 없애면 길이 막힘):

- **왼쪽 위 「뒤로」와 아래 왼쪽 「이전/지도」**: 위는 페이지 기록 뒤로(새로고침·이어하기 직후에는 기록이 없어 비활성), 아래는 활동 순서의 이전 단계·지도(항상 사용 가능). 이어하기로 들어온 학생에게는 아래 버튼이 이전 단계로 가는 유일한 길이라 유지.
- **1장 관찰의 부위 버튼(눈·뒷다리·몸 표면)과 3D 표본 위 점**: 부위 버튼은 키보드·그림 모드(WebGL 없음)의 유일한 조작이라 유지.
- **3장 영상의 큰 재생 버튼과 재생 막대 ▶**: 큰 버튼은 시작, 막대는 멈춤·다시 재생. 일반 영상 조작이라 유지.
- **지도 건물 표시와 오른쪽 아래 「○○으로 가기」**: 건물은 아무 곳이나, 주 버튼은 다음 갈 곳 한 곳. 3초 규칙의 주 버튼이라 유지.
- **설계 화면 「특징 선택·부품 배치」 체크와 선택 판 단계 탭**: 버튼이 아닌 진행 표시와 단계 탭이라 이번 범위(버튼) 밖. 진행 표시 중복은 개선 권장으로 남김.
