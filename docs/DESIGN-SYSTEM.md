# 디자인 기준 · 0.2.0

## 방향

자연 기록 연구소의 차분한 초록·크림색을 유지하고, 귀여운 안내 캐릭터와 관찰에 적합한 동물 이미지를 함께 쓴다. 지도만 픽셀아트이며 학습 화면은 명확한 정보 위계를 가진 표본·기록판으로 구성한다.

## 색·글꼴·규격

- 본문 `#263e34`, 보조 `#56665a`, 주 행동 `#2e523e`, 선택 `#dcecb1`, 배경 `#f6f5ee`, 기록판 `#fffef9`.
- 기존 Malgun Gothic / Apple SD Gothic Neo / system-ui 폰트 유지. 웹폰트 없음.
- 본문 16–22px, 큰 화면 학습 본문 최소 20px, 주요 설명 20–26px. 큰 제목 28–40px. 장식적인 영문·상태 표기는 더 작음.
- 버튼 최소 48px, 주요 CTA 50–58px. 키보드 초점은 3px 황갈색 테두리.
- 패널 모서리 24px, 본문 줄간격 1.55–1.7. 한글 단어 단위 줄바꿈, 긴 입력값 줄바꿈.
- 한 화면의 주 행동은 하단 오른쪽. 잘못된 선택은 처벌 대신 다시 확인할 근거를 안내.

## 화면별 구성

- 홈: 연구소 배경, 왼쪽 제목·시작, 오른쪽 모리. 모바일은 아래쪽 모리와 세로 배치.
- 관찰: 밝은 표본 공간 + 별도 기록판, 새 이미지에 맞춘 관찰점.
- 분류: 동물 카드와 두 선택. 모호한 기준과 관찰 가능한 기준의 결과 비교.
- 환경: 지형·물·연잎·갈대·동물을 별도 레이어로 구성.
- 추리: 정체를 미리 드러내는 그림 대신 기록철·돋보기 이미지.
- 설계: 구조 선택에 따라 안전모·오리발·외투 이미지 변경. 펜 선은 별도 SVG 레이어.
- 시험·성취: 실패/통과 상태와 실제 관찰 수·환경 수·시험 수를 표시.

## 반응형과 접근성

1920×1080, 1440×900, 1280×800, 1024×768, 768×1024, 915×412, 375×812의 대표 화면을 확인했다. 좁은 화면에서는 기록판을 아래로 쌓고 세로 스크롤을 허용한다. 고정된 한 화면 안에 모든 내용을 축소하지 않는다. 이미지 alt, 선택 pressed 상태, dialog, 저장 경고, reduced-motion을 제공한다. 실제 교실의 거리·터치펜·스크린리더 검수는 별도다.

## 3D 교체 원칙

`src/assets.js`의 ID와 `model.js`의 학습 ID를 유지한다. 이미지 렌더링과 `productArt`의 표현만 교체하며 완료 조건·저장 포맷을 변경하지 않는다. 포인터 관찰점 좌표는 3D 모델 투영 좌표로 재설정해야 한다. 원본 PNG를 모델 제작 레퍼런스로 사용한다.
