# 자연 기록 전시관 확장 · 0.5.0

목표는 활동을 더 푸는 데서 끝나지 않고, 관찰한 사실을 주민의 부탁에 사용하여 전시관을 다시 여는 것이다. 기존 20개 탐색 활동·3D 표본·생태 돔·드래그·비교 시험을 유지한다.

| 장소 | 본 미션 | 응용 미션 | 남는 결과 |
|---|---|---|---|
| 관찰의 숲 | 개구리·게의 잘못된 설명판과 확인 부위 수리 | 오리·토끼의 몸 표면과 공통점 전시 | 몸의 특징 전시대, 관찰가 배지 |
| 분류의 정원 | 닭·박쥐·벌·달팽이를 날개 유무로 배치 | 스스로 고른 관찰 가능한 기준으로 재배치 | 실제 선택 기준과 분류 결과, 분류가 배지 |
| 생태의 물가 | 토끼·바다 물고기의 환경→몸→움직임 방송 | 오리·나비의 새로운 방송 | 두 방송 원고, 생태 해설가 배지 |
| 동물 찾기 안내소 | 두 특징과 생활로 개구리·게 기록 반환 | 벌·달팽이 기록 반환과 구별 근거 선택 | 네 반환 기록, 근거 탐정 배지 |
| 발명의 공방 | 첫 발명품을 새 손님의 조건으로 비교 시험 | 두 번째 발명품을 다른 조건으로 비교 시험 | 선택한 모양·시험·이유, 생활 발명가 배지 |

각 장소에 선택 도전 1개를 추가했다. 총 20개 탐색 활동 + 10개 의뢰 + 5개 선택 도전이다. 새 의뢰에 시간 제한·목숨·추가 에너지를 넣지 않는다. 틀리면 해당 근거를 다시 확인하고 수정한다. 기존 4장에는 조사→동물 선택→근거 연결 표시와 현재 단서에 맞는 후보 수를 보인다.

새 탐험에서는 탐색 4개와 의뢰 2개를 마쳐야 장소 복구·다음 장소·기존 도구 보상이 열린다. 별은 기존과 같이 최대 20개다. 새 의뢰와 선택 도전은 별 대신 전시 기록·배지·도장으로 남으며 반복 보상을 주지 않는다. 완료한 기록은 초안과 분리하여 다시 풀거나 잘못 수정해도 전시물이 바뀌지 않는다.

이전 저장에서 이미 받은 장소와 도구는 유지한다. 새 의뢰를 했다고 가정하지 않으며, 각 장소나 전시관에서 추가 의뢰를 시작할 수 있다. 관리자 입장 해금만으로는 의뢰 보상을 주지 않는다.

보상 도구는 새 의뢰의 작업대에서도 사용한다. 관찰 렌즈는 몸의 특징 자료를 펼치고, 분류 나침반·서식지 수첩은 직접 발견한 환경·움직임 기록을 보여 준다. 특징 스캐너는 동물의 구조와 물건의 구조를 연결한다. 모리는 계속 하루를 따라가는 기록 보조원이며, 지도 주민의 기존 역할과 이름을 유지했다.

발명 재시험은 실측 성능이 아닌 설명 모형이다. 오리발은 미는 물과 필요한 힘, 보호 덮개는 가리는 범위와 재료 사용량, 보온 옷은 보온과 움직임의 불편함을 비교한다. 손님의 요구를 명시해 정답이 모호해지지 않게 했다. 조건이 같은 상태에서 모양만 바꾸며, 서로 다른 두 모양과 선택한 모양의 실제 시험 기록이 필요하다.

메인은 새 생성 이미지 `assets/adventure/museum-opening.webp`를 사용한다. 지도는 기존 복구 전후 이미지·인물 스프라이트·길 이동을 재사용하며, 목표 문구를 지도 위 별도 줄로 옮겨 첫 장소 버튼을 가리지 않는다. 의뢰에는 주민 초상·도감 이미지·나무 작업대·종이 기록을 사용하고, 전시관에는 학생이 완성한 내용만 전시한다. 추가 본문은 기존 태블릿 가독성 기준인 18px, 보조 글자는 16px를 적용한다.

구현: `src/campaign.js`, `src/campaign-views.js`, `src/campaign.css` 및 기존 제어·저장·화면·빌드 연결. 검증 범위는 `reviews/MUSEUM-QA-20261018.md`를 참고한다.

초기 공유 대화 링크는 본문에 접근하지 못하여 프로젝트의 원본 PRD와 이전 구현·합의된 계획을 기준으로 대조했다. 실제 학생의 활동 시간과 이해도는 교실 사용으로 확인해야 한다.
