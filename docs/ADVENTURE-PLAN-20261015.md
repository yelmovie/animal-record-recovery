# 탐험형 개편 계획 · 0.3

사용자 요청: 모호한 4장 개선, 장별 문제 분량 2배, 이미지 중심의 지도와 사람 주인공·너구리 보조원, 학습과 연결되는 보상·흥미.

## 교육 목표

제공 PRD와 교육부 2022 개정 과학과 교육과정의 동물의 생활을 대조한다.
- [4과02-01] 몸의 특징을 관찰해 비교·분류하기: 1·2·4장.
- [4과02-02] 환경과 몸·생활의 관계 설명하기: 3·4장.
- [4과02-03] 동물 특징을 활용한 생활용품 설계와 의사소통: 5장 및 결과 공유 질문.

4장은 ‘미확인 동물을 제한된 단서로 수사’하는 추상적 활동을 ‘사진의 특징 두 개 고르기 → 알맞은 동물 명찰 → 사는 곳과 그곳에서 움직이는 방법 연결’로 바꾼다. 오리·토끼의 두 사진을 사용한다. 장소만으로 이름을 맞히거나 정답을 찍는 것으로 완료되지 않는다.

## 분량: 10 → 20개 활동

| 장 | 1·2 활동 | 3·4 활동 |
|---|---|---|
| 1 관찰 | 개구리·게 6곳 관찰 / 공통점·차이 비교 | 오리·토끼 6곳 관찰 / 공통점·차이 비교 |
| 2 분류 | 6종 날개 기준 분류 / 기준 검증 | 6종 다리 네 개 기준 분류 / 다른 기준 검증 |
| 3 환경 | 3환경에서 첫 동물 발견 / 개구리 연결 | 3환경에서 다른 동물 발견 / 토끼 연결 |
| 4 동물 찾기 | 오리 특징·명찰 / 물가·물갈퀴·헤엄 연결 | 토끼 특징·명찰 / 숲과 들·뒷다리·뛰기 연결 |
| 5 발명 | 세 문제 중 첫 설계 / 시험·수정·설명 | 첫 문제와 다른 두 번째 설계 / 시험·수정·설명 |

## 역할과 보상

- 학생을 대신하는 사람 탐험가 ‘하루’: 지도 길을 따라 이동, 관찰·설계의 주체.
- 너구리 ‘모리’: 하루를 따라다니는 기록 보조원. 맥락에 맞는 짧은 말과 실제 수집 기록으로 힌트 제공.
- 활동 검증 1회당 탐험 별 1개(최대 20). 재클릭·속도·첫 시도에 추가 점수를 주지 않는다.
- 1장 관찰 렌즈: 이후 몸 특징 도감 열기.
- 2장 분류 나침반: 이후 환경 탐색에서 남은 발견 확인.
- 3장 서식지 수첩: 4장 환경 설명에서 실제 발견 기록 참고.
- 4장 특징 스캐너: 5장 이전 관찰·특징과 발명 기능을 대조.
- 5장 발명가 배지: 두 발명과 수정 기록을 담은 최종 연구 기록.
- 장 완료 시 해당 지도 장소에 복구 표시·다음 경로 해금. 최종 지도에 5곳 복구 및 탐험대 귀환 연출.

보상은 소모하지 않으며 틀린 답에 생명·기회를 빼지 않는다. 도구는 결과를 대신 제출하지 않고 관찰·기록 확인을 돕는다.

## 구현·검증

기존 vanilla JS 유지. 콘텐츠·상태를 expedition 모듈로 분리하고 이미지 중심 지도와 단일 공통 UI로 구성한다. 기존 저장은 보관하고 기존 첫 탐구의 확인 가능한 기록만 이관한다. 새로운 추가 활동을 자동 완료 처리하지 않는다. 4장 변경 내용은 다시 탐험한다.

새 PNG 원본·WebP·프롬프트를 D: 프로젝트에 보존한다. 20활동 정답·오답·보상 중복 방지·저장 복원·관리자 해금·키보드/터치·주요 해상도와 실제 로컬 빌드를 검증한다. 기존 0.2 검수 보고서는 과거 버전으로 유지한다.
