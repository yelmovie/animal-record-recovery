# 자연 기록 전시관 확장 검증 · 2026-10-18

대상: 0.5.0. 기존 별 20개에 의뢰 10개와 선택 도전 5개를 추가한 버전.

## 자동 검증

- `npm run check`: JavaScript 구문 검사 통과.
- `npm test`: 90개 통과. 기존 79개 + 캠페인 모델 9개 + 컨트롤러 연결 2개.
- 검사 항목: 탐색만 완료했을 때 복구·도구·다음 장소 잠금, 의뢰 순서, 오답·미완료 차단, 15개 추가 활동 완주, 중복 보상 방지, 초안과 제출 기록 분리, 저장 복원, 이전 완료·도구 보존, 변조·손상 기록 정규화, 분류 기준 변경, 세 종류 발명과 조건별 비교, 입력 이스케이프, 초기화·뒤로가기·드래그 대체 터치 연결.
- `npm run build`: 93개 런타임 파일, 13.52 MiB. 개발용 검증 서버·테스트·PNG 원본은 배포에 포함하지 않는다.

## 실제 브라우저 검증

기존 탐색을 모두 끝낸 검증용 저장을 별도 로컬 주소 `127.0.0.1:4178`에 준비했다. 이 주소에서 **새 의뢰 10개와 선택 도전 5개를 실제 화면 조작으로 모두 완료**했다. 기존 20개 탐색 전체를 이번에 다시 수동 완주한 것은 아니며, 기존 자동 회귀 검사와 새 연결 검사를 실행했다. 사용자 저장이나 운영 주소의 기록을 덮어쓰지 않았다.

- 관찰: 잘못된 껍데기 설명을 제출해 몸 표면 재확인 안내 확인, 수정 후 두 전시 설명판 완성.
- 분류: 클릭 선택→칸 제목 배치, 달팽이 실제 드래그, 기준 변경 시 배치 초기화, 관찰 렌즈 자료 펼치기 확인.
- 생태: 네 동물의 환경·몸·생활 12개 연결을 제출하고 방송 전시 확인.
- 찾기: 동물은 맞지만 구별 근거가 틀린 경우 완료를 막고, 다른 특징을 비교하도록 안내하는지 확인.
- 발명: 예상 없는 시험 차단, 서로 다른 시험 축적, 시험하지 않은 모양 제출 차단, 손님 조건에 맞춘 수정, 두 발명의 의뢰 완료 확인.
- 재방문·새로고침: 첫 장소 완료 후와 마지막 발명 도중 새로고침해 완료 기록 및 초안 유지 확인.
- 최종 전시관: 의뢰 10/10, 선택 도전 5/5, 별 20/20. 실제 선택 기준·전시 문장·시험한 모양이 표시됨.
- 지도: 장소 복구 이미지와 5개 도구, 하루와 모리 이동, 전시관 재개장 목표 확인.

검증 중 분류 칸 전체가 하나의 버튼이면 이미 놓인 카드에 터치가 걸리는 문제를 발견했다. 칸 제목에 별도 배치 버튼을 두고 드래그 영역은 유지한 뒤 연속 배치와 드래그를 재검증했다. 목표 안내가 첫 장소를 가리는 문제는 지도 밖의 별도 줄로 옮겨 해결했다.

화면 검증과 캡처: `screenshots-v5/`. 기본 데스크톱, 1024×768 태블릿, 375×812 휴대폰에서 확인했다. 가독성 조정 후 본문·선택지 18px 적용을 DOM으로 확인했고, 최종 태블릿·휴대폰 화면에 가로 넘침이나 이미지 로드 오류가 없었다. 휴대폰에서는 지도 아래 장소 설명과 시작 버튼이 표시되는 것을 확인했다. 브라우저 크기 변경은 실제 모바일 기기 테스트를 대체하지 않는다.

## 최종 빌드·전달 파일

- 최종 빌드 전용 주소 `127.0.0.1:4179`에서 새 저장으로 홈→도입→지도→첫 장소를 진행해 개구리 3D 표시와 다음 장소 잠금을 확인했다. 브라우저 콘솔 오류는 없었다.
- 기록 내보내기 창의 2,496자 텍스트에서 전시관 의뢰 기록, 직접 정한 분류 기준, 세 가지 수영 모양 시험, 선택 도전 기록을 확인했다. 실제 TXT 다운로드 클릭은 이번 수동 검증에 포함하지 않았다.
- 빌드 목록의 런타임 파일 93개 모두 HTTP 200, 파일 크기 일치, JavaScript MIME 형식을 확인했다. 런타임 파일 총합은 14,181,616바이트다.
- `delivery/animal-record-recovery-web-0.5.0.zip`: 12,899,324바이트. 런타임 파일 93개와 빌드 목록 1개, 총 94개 항목이며 루트에 `index.html`이 있다.

## 검증 범위의 한계

실제 학생·교사 사용성, 실제 iPad/Safari·전자칠판, 운영 네트워크는 이번 로컬 검증에 포함하지 않는다. 발명 비교 막대는 설명 모형이며 물리 성능 측정값이 아니다. 기존 0.4 공개 배포를 이번 검증 중 변경하지 않았다.
