# 스테이지 선택 지도 개선 · 2026-10-19

아이스크림 스킬의 건물형 지도 패턴을 기존 동물 마을에 적용했다. 기존 그림·활동·학습 순서와 작업 중이던 설정·가독성 변경을 유지했다.

- 건물에 탐험 가능·잠김·복구 완료, 실제 획득한 별을 표시한다. 다음 탐험 장소를 강조하고 하단에 바로 가기를 제공한다.
- 잠긴 건물의 그림·라벨을 누르면 현재 먼저 복구할 장소와 이동 버튼을 안내한다.
- 길 클릭, 방향판, 방향키/WASD, 문 앞 Enter를 지원한다. 이동은 연결된 길을 따르고, 공방에도 다리를 경유하는 경로를 추가했다.
- 설정·장소 정보가 열리면 이동을 멈춘다. 닫기·Escape 이후 다시 조작할 수 있다. 문에서 걸어 나올 때 곧바로 재입장하지 않는다.
- 교사용 전체 단계 해금은 확인 코드 없이 제공한다. 미리보기는 메모리 복사본을 사용하고, 종료·새로고침 시 학생 기록과 잠금으로 돌아간다.

## 변경 파일

- `src/shell-views.js`, `src/stage-map.css`: 지도 구성·상태 표시·태블릿 배치
- `src/adventure-app.js`, `src/village.js`, `assets/village/village.json`: 선택·이동·팝업·미리보기 분리
- `src/expedition.js`, `src/settings-content.js`, `src/workspace.css`: 영구 해금과 확인 코드 제거
- `index.html`, `scripts/build.mjs`: 지도 스타일 로드·빌드 포함
- `tests/adventure-app.test.mjs`, `tests/settings.test.mjs`, `tests/village.test.mjs`: 저장 분리·잠금 안내·이동 경로 회귀 검증

## 검증

- 전체 자동 테스트 155개 통과, JavaScript 구문 검사 통과.
- 격리된 4191 포트의 테스트 저장본으로 잠금 안내 → 첫 장소 입장, 실제 주민 답장 제출 → 첫 장소 복구 → 다음 단계 해금·입장 → 다시 열어 기록 유지 확인.
- 교사용 마지막 장소 입장·작품 이름 수정·미리보기 종료 후 학생 상태 복구 확인. 저장본 불변은 자동 테스트로도 검증.
- 키보드 이동, 방향판으로 문 진입, 설정 중 위치 정지, 장소 정보 Escape 닫기 확인.
- 1024×768, 1180×820, 1280×800, 768×1024, 820×1180에서 가로 넘침·주요 버튼 잘림 없음. 주요 조작 영역 최소 44 CSS px 이상.
- 브라우저 마우스·키보드 입력으로 검증했다. 실제 태블릿 터치는 미검증이다.
- 캡처·레이아웃 측정·테스트 로그: `output/stage-map/`.
- 배포 파일은 `dist/`에 빌드했다. 운영 배포는 하지 않았다.
