## 완료

- `src/readability.css`: 가로 1000px 이상·높이 651px 이상에서 주요 제목 30~40px, 중간 제목 26~34px, 핵심 본문·버튼 20~26px로 자동 확대. 보조 정보는 16px 이상 크기 토큰 사용. 선택 탭의 글자 대비 보강.
- 확대에 맞춰 발명 관찰·부품 카드 폭과 배치, 공방 소개 그림 높이·입력란 간격, 아이디어 노트 폭, 주민 부탁의 질문·결과 간격 조정. 이미지 비율과 학습 선택지는 유지했다.
- `src/settings-content.js`, `src/shell-views.js`: 기록 저장 위치·기기/주소별 분리·삭제 전 내려받기·공용 기기 주의·초기화 확인 안내 추가. 기존 자체 제작물/외부 자료의 권리 구분 유지. 자료 출처는 화면에서 확인하도록 바꾸고, 제공받은 동물 영상 6종을 Kling 생성분과 구분했다.
- `src/audio.js`, `src/adventure-app.js`, `src/expedition.js`: 독립 효과음 음량 조절(0~100%) 추가. 저장·복원, 음소거 시 비활성화, 기록 초기화 시 소리 설정 유지. 이전 저장은 기존 80% 음량을 기본값으로 사용한다.
- `src/studio-views.js`: 아이디어 노트의 두 안내 문장을 같은 의미로 짧게 정리했다.
- 설정은 긴 문서를 내부 스크롤로 읽고, 제목·닫기·초기화 버튼은 스크롤과 분리해 화면에 유지한다.
