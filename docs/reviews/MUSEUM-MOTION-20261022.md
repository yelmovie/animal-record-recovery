# 전시관·영상 사진 UX 검증 (2026-10-22)

- 3장 영상은 큰 중앙 재생 버튼, 재생/일시정지, 실제 시간 탐색, 느린 재생으로 조작한다. 번호별 장면 선택과 특정 순간 정답 판정을 제거했다.
- 후속 사용자 요청으로 ‘내 예상’ 선택 영역과 촬영 전 예상 조건을 제거했다. 실제 재생한 영상에서 원하는 순간을 한 장 찍는다. 멈추고 탐색한 뒤에도 촬영할 수 있다. 동물마다 사진 한 장만 보관하며 다시 찍기는 해당 사진을 교체한다.
- 영상 오른쪽 위 전체화면 아이콘으로 같은 플레이어를 확대한다. 재생·탐색·사진 촬영 버튼도 함께 표시한다. 브라우저에서 1920×1080 전체화면 진입, 예상 없이 촬영, 닫기 아이콘으로 원래 화면 복귀를 확인했다. 컨테이너 전체화면이 없는 브라우저에는 네이티브 영상 전체화면을 사용한다.
- 사진은 canvas로 실제 영상 프레임을 저장한다. 최대 480×360, 64,000자 이내로 제한한다. 영상 미재생·탐색 중·영상 오류·canvas 실패 시 기존 사진을 보존한다. 대체 설명 그림을 영상 사진으로 위장하지 않는다.
- 기존 관찰 완료 기록은 유지한다. 모든 필수 동물을 관찰해야 다음 활동으로 진행하는 조건도 유지한다. 사진은 브라우저 로컬에만 저장한다.
- 전시관은 새 자연사 박물관 배경, 유리 진열장, 호두나무 받침, 소장번호, 작품 설명판을 사용한다. 제출한 답안·분류 기준·그림·방송 원고를 전시하며 미완료 전시물은 만들지 않는다.
- 촬영 사진을 전시관 사진벽과 확대 보기로 연결했다. 실제 토끼 영상의 0.0초 촬영, 5.0초 재촬영 후 한 장 교체, 새 페이지 진입 후 유지, 전시관 사진벽과 확대 보기를 브라우저에서 확인했다. 실제 저장 이미지 크기는 480×270이었다.
- 데스크톱 1920×1080, 1280×720, 태블릿 1024×768, 세로 768×1024에서 화면을 확인했다. 긴 기록은 패널 안에서 스크롤한다. 실물 태블릿 터치 검증은 수행하지 않았다.
- 편지 본문에 기존 로컬 주아체를 적용하고 글씨를 키웠다. 편지 아래 여백을 줄이고 내용에 맞춰 높이를 조절한다.
- 지도 초기 CSS 크기를 카메라의 100% 맞춤 기준으로 통일했다. 실제 슬라이더 100→110→200%에서 지도가 커지고, 휠 위로 확대·아래로 축소되는 것을 확인했다.
