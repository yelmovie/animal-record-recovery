- 같은 오답 안내가 폭 182px·높이 212px에서 폭 495px·높이 72px로 바뀌었다(1180×757). 패널 내 좁은 열과 중첩 스크롤을 없앴다.
- `1024×768`, `1180×820`, `1180×757`, `768×1024`에서 정상 관찰·오답·사진 기록·긴 소개·시험 결과·설정·일기·확대·편지 닫힘을 확인했다. 사진의 세로 배치는 추가로 재검사했다. 최종 시험 결과 패널의 내용 넘침은 네 크기 모두 없었다. 입력 칸 자체의 긴 글 스크롤은 일반 편집 기능으로 유지한다.
- 별도 새 localhost 진도로 1~5장, 관찰 12개, 생활 근거 연결, 주민 편지 5통·답장, 비교 시험, 자유 작품, 마을 전체보기, 엔딩 영상 종료, 전시관, 인증서까지 실제 UI로 완주했다. 교사용 전체 해금으로 완주한 것이 아니다.
- 3D 돔에서 DOM 버튼으로 여섯 동물을 발견하고 실제 영상을 재생해 촬영했다. 예상 선택은 요구하지 않았다. 직접 다운로드한 완주 백업에는 활동 18개, 관찰 12개, 사진 6장, 의뢰 제출 10개(편지 5통), 한글 작품과 그림이 포함됐다. 첫 관찰은 도움 후 정답 1개, 첫 응답 정답 11개로 구분됐다.
- JSON 파일 실제 다운로드 → UTF-8 한글 확인 → 파일 다시 열기 → 확인 후 복원 → 일기·인증서 재진입을 실행했다. 같은 파일을 파서로 왕복해 사진·작품·진도를 비교한 결과도 일치했다. 작품 PNG도 실제 다운로드하고 이미지로 열어 그림과 한글 소개를 확인했다.
- 손상 JSON·미지원 버전·용량 초과·저장소 접근 차단을 별도 localhost fixture에서 재현했다. 손상 문자열 `{손상된 원본`은 그대로 파일로 내려받혔다. 복원과 초기화는 자동 실행되지 않는다. 초기화 확인에서 취소도 실행했다.
- 새로고침·이어하기 후 제목·긴 소개·그림 유지, 카드→칸 탭 배치와 키보드 Enter, 뒤로 이동, 도형 추가·Undo/Redo, 마우스 자유 펜 입력·Undo/Redo를 확인했다. 반복 클릭의 보상 중복 방지는 이번 controller 회귀 테스트에도 포함됐다.
- 동물 영상을 HTTP 404로 실패시켜 설명 그림과 관찰 기록으로 이어지는 것을 확인했다. 실패한 영상에서 실제 사진을 생성한 것처럼 저장하지 않았다.
- 완료 마을의 여섯 간판은 네 크기 모두 화면 밖으로 잘리지 않았다. 걸어보기로 바꾸면 추종 카메라가 다시 작동했다. 화면 밖 지도 그림 자체는 오류로 처리하지 않았다.
- 768×400으로 높이를 줄인 키보드 모의 검사에서 소개 칸 폭 691px, 완료 버튼의 전체 영역이 보이는 것을 확인했다. 이는 실제 모바일 가상 키보드 검증이 아니다.
