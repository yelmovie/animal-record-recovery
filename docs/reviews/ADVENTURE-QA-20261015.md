# 탐험형 개편 검증 · 0.3.0

이번 요청의 구현과 로컬 검증을 완료했다. 공개 배포는 하지 않았다. 0.2 버전의 점수 보고서는 과거 버전이며 이번 점수를 대신하지 않는다.

## 변경과 학습 연결

| 장 | 활동 분량 | 보상과 다음 효용 | 교육 목표 연결 |
|---|---|---|---|
| 1 관찰 | 2→4. 두 동물쌍, 관찰점 6→12, 비교 두 번 | 관찰 렌즈로 몸의 특징 도감을 열어 분류·동물 찾기에 활용 | [4과02-01] 형태 관찰·공통점과 차이 |

4장은 사진 특징 두 개를 맞추면 명찰 카드가 나타나는 순서로 바꿨다. 틀린 특징을 두 개 고르면 바로 수정 안내가 나오며 기회나 생명을 빼지 않는다. 특징을 다시 살펴보는 기능도 있다. 정체 맞히기만으로 통과하지 않는다.

하루는 탐험의 주인공, 모리는 길을 따라다니며 실제 발견을 기록하는 보조원이다. 처음에 역할과 전체 목표를 보여 준다. 별은 검증한 활동에 한 번만 지급하고 속도·반복 클릭을 보상하지 않는다. 네 활동을 마치면 지도 장소에 복구 표시가 생기고 다음 길이 열린다. 받은 도구는 가방과 활동 화면에서 실제 기록을 보여 준다.

## PASS · 실행 확인

- `npm run check`: 현재 코드와 빌드 스크립트 구문 통과.
- `npm test`: 41/41. 현재 탐험 모델·제어기·제출 기록 18개, 이전 버전/저장·내비 회귀 23개.
- 전달 빌드: 실행 파일 32개·약 5.07 MiB. 모든 실행 파일 HTTP 200과 이미지·모듈 MIME 확인. ZIP에는 실행 파일과 매니페스트만 33개 포함.
- 빌드 서버의 새 주소에서 첫 출발·역할 안내·관찰 1개·새로고침 후 관찰 기록 1/6 복원 확인. 깨진 이미지 없음.
- 정상 경로: 별 0개에서 출발하여 20활동 순서대로 완료. 최종 별 20개, 복구 5곳, 도구 5개, 카드 7종, 서로 다른 발명 2개 확인.
- 오답 경로: 미완료 관찰, 모호한 분류 기준, 잘못된 특징 두 개, 첫 발명의 잘못된 구조를 수정하고 진행.
- 재사용 보상: 관찰 렌즈 → 분류, 나침반 → 환경, 서식지 수첩 → 4장, 특징 스캐너 → 발명에서 실제 기록 내용 확인.
- 저장: 첫 발명 후 두 번째 설계 이름과 선택이 새로고침 후 복원. SVG 설계선 1개를 직접 그려 기록·인증서·TXT에 유지.
- 최종 기록: 12개 관찰, 6개 환경 발견, 두 동물 안내 카드, 오리발·외투 두 발명, 총 3회 시험과 설계선 반영.
- 완료 후 다시 편집하는 초안이 이전 통과 발명과 안내 카드 제출 기록을 덮어쓰지 않는 회귀 테스트 통과. 새 성공 제출 때만 갱신.
- 기존 저장 이관: 0.2 완료 장소와 관찰을 보관하고 확인 가능한 첫 활동만 이관. 바뀐 4장이나 새 활동은 자동 완료하지 않음.
- 관리자 입장 해금으로 별·보상·완료 상태를 얻지 않는 제어기 테스트 통과. 초기화 후 진행과 이전 완료 경로 제거 검증.
- 지도 이동: 모든 장소 간 경유점 경로 검사. 실제 이미지 길에 맞춘 경유점으로 이동하며 모리가 뒤에서 따라감. 선택 경로를 밝게 표시하고 도착 후 사람 캐릭터가 해당 장소 표시를 대신함.

## 수정한 검증 중 문제

- 새 보상 배경의 큰 blur 레이어에서 브라우저 캡처·입력이 지연되어 blur를 제거하고 동일 보상 화면의 조작·캡처를 다시 확인했다.
- 기존 디오라마 시트가 3열×4행인데 다른 규격으로 표시되는 문제를 바로잡았다.
- 연못에는 실제 물과 수생 식물이 보이는 디오라마를 적용했고, 바닷가 물고기는 바위 대신 물 위에 배치했다.
- 4장 특징과 명찰을 동시에 보여 줄 때 명찰이 아래로 밀리는 문제를 단계별 표시로 개선했다.
- 작업 중 생긴 템플릿 구문 오류를 수정한 후 전체 구문·테스트를 재검증했다.

- 학교의 실제 Safari/Android 태블릿·터치펜·전자칠판 거리 판독·스피커: 장비 검수 미실시.
- 운영 URL·교실 동시 접속·약한 네트워크·완전 오프라인: 외부 배포와 네트워크 장애 시험 미실시.
- 최종 AI 동물 형태와 교사의 수업 적합성 승인: 교사 검수 필요. 2D 게임 모델은 실제 표본을 대신하지 않는다.
