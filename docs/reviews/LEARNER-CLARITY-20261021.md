## 미검증 (하지 못한 것)

- **실제 Android·iPad 태블릿, Safari, 실제 가상 키보드, 전자칠판, 학교 네트워크**: 확인하지 않았다. 위 결과는 데스크톱 브라우저의 크기 에뮬레이션이다.
- 3D 생태 돔에서 손가락으로 동물을 눌러 발견하는 동작: 캔버스 탭은 자동화하지 못했다. 같은 코드 경로(`onFind`)는 노드 테스트로, 예상 전 화면은 3D 모드 캡처로 확인했다. 전체 경로 클릭 진행은 2D 모드다.
- 지도 걷기: 브라우저 창이 숨겨진 상태라 애니메이션이 느렸지만 도착·입장은 됐다. 실기기 속도는 미확인.

## 2차 수정 (같은 날, 1차 남은 문제 처리)

| 1차 남은 문제 | 처리 |
|---|---|
| 저절로 열린 모리 말풍선이 활동 칸을 가림 | 저절로 열린 말풍선(`.auto`)은 모리 오른쪽 아래 줄, 다음 버튼 앞까지만 차지한다(`fitBubble()`, 화면 회전 때 다시 맞춤). 1920×1080·1280×800·1024×768·768×1024에서 활동 버튼과 겹침 0 |
| 세로 생태 돔·신발 그림이 작음 | 돔 아래 빈 여백(92px, 다른 규칙의 `!important`)을 걷어 돔 높이 200 → 285px. 신발은 안내 글이 진행 표시 목록 안에 들어가 작아지던 것이라, 안내를 실제 선택 칸(특징 고르기) 옆에 붙이도록 바꿔 124 → 237px |
| 3장 연결 칸 안내가 최대 3문장 | 처음 고칠 칸 하나만 한 문장으로 알리고, 고칠 칸은 모두 테두리로 표시 |
| 반복 안내 | 1장 “맞는 설명을 골라 봐”(아래 ‘하나를 골라 눌러 봐’와 중복) → “설명과 비교해 봐”. 3장 예상 전 문구 4곳 → 2곳(왼쪽 설명 끝·자막의 ‘예상’ 반복 제거, 자막은 자리만 유지) |
| 그림판 `setPointerCapture` 콘솔 오류 | 그림판·색상판·렌즈·스케치에서 포인터 고정 실패를 무시(선은 그대로 그려짐) |

## 남은 문제

- 자료 이용 조건 미확인 항목(사용자 제공 ChatGPT 그림, 사용자 제공 움직임 영상 6종)은 코드로 해결할 수 없다. 생성 계정·요금제를 사용자가 확인해야 한다(`docs/DELIVERY.md` 표).
- 실제 태블릿·Safari·가상 키보드·전자칠판 확인은 여전히 하지 않았다.
