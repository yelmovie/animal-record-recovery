# 방송 의뢰·연구 일기·손전등 탐구 검증

사용자가 요청한 세 가지 변경을 함께 적용했다. 새 생성 이미지는 만들지 않았으며 기존 동물 사진·환경 그림과 CSS를 재사용했다.

## 방송 의뢰

- 큰 동물 사진과 이름을 왼쪽에 고정하고, 오른쪽은 그 동물의 사는 곳·몸의 부분·움직이는 방법을 고르게 했다.
- 현재 빈 질문을 강조하고, 선택하면 다음 질문으로 안내한다. 선택 상태를 정답 여부로 표시하지 않는다. 기존 판정과 제출 기록은 유지한다.
- 세 줄을 고르면 다음 미완료 동물의 이름이 적힌 버튼이 활성화된다. 모든 동물을 채운 뒤에는 답장 보내기로 이어진다. 이미 제출한 의뢰는 전시관 보기로 이어진다.
- 긴 방송 원고는 펼쳐 보기로 이동했다. 1280×720에서 다음 버튼이 패널 안에 보이는 것을 확인했다. 실제 바다 물고기 선택→다음 질문 강조→오리 사진과 질문 전환을 실행했다.

## 연구 일기

- TXT 링크·Blob 생성·다운로드 URL을 현재 실행 앱에서 제거했다. 전시관과 인증서에서는 ‘나의 탐험 일기’를 연다. 이전 버전 보관용 `src/app.js`는 로드하거나 배포하지 않는다.
- 줄 공책, 제본 구멍, 사진과 동물 스티커, 주아체 본문을 적용했다. 기존 숫자 집계와 항목별 답안 목록 대신 실제 관찰·발견·제출·작품과 학습자의 메모를 문장으로 엮는다.
- 빈 기록에는 경험을 지어내지 않는다. 저장된 설명이 없는 특징을 추가하지 않으며 주민을 도왔다는 문장은 실제 제출 뒤에만 표시한다. 학습자가 쓴 글은 HTML 이스케이프한다.
- 768×1024에서 주아체를 실제 계산 스타일로 확인했고, 본문 스크롤과 ‘노트 덮기’ 버튼이 모두 보이는 것을 확인했다.

## 4스테이지

- 네 활동 모두 재구성했다. 오리·토끼를 조사하는 두 활동은 큰 동물 사진을 어둡게 가린 뒤 손전등으로 특징을 찾는다. 발견 장소·몸의 모습·발/귀·이동 모습·생활 장면을 팝업에서 읽고 수첩에 붙인다.
- 입력→빛 이동→반짝이는 지점 선택→발견 팝업→수첩 붙이기→다음 특징 조사로 이어진다. 클릭/드래그와 키보드 포커스가 같은 빛 위치를 사용한다. 재렌더 시 포인터 리스너와 캡처를 정리한다.
- 종전 조사 에너지 세 번 제한은 제거하고 다섯 특징을 모두 발견할 수 있게 했다. 같은 단서 재열람은 중복 기록하지 않는다. 기존 세 단서 저장은 그대로 복구한다.
- 서로 다른 단서 두 개 이상을 찾은 뒤 동물을 추리한다. 발견한 단서 중 판단 근거 두 개 이상을 직접 고르는 조건과, 그 근거가 다른 후보와 구별되는지 판정하는 규칙은 유지한다.
- 토끼의 털+귀를 근거로 고르면 박쥐도 해당한다는 피드백이 나오는 것을 실제 브라우저에서 확인했다. 이동 단서를 추가하고 근거를 바꾸면 진행되는 것도 확인했다.
- 이어지는 두 생활 활동은 큰 동물을 집으로 안내하는 화면이다. 환경 그림을 선택하고 움직임 버튼을 누르면 짧은 설명 애니메이션을 보여 준다. 실제 동물 영상이 아닌 선택의 시각적 표현이며, 사는 곳과 움직임의 정답 판정은 기존 모델이 담당한다. 동작 감소 설정에서는 움직임 애니메이션을 하지 않는다.
- 실제 오리의 깃털·물갈퀴 발견→추리→근거→연못·헤엄 선택→토끼 조사→근거 수정→숲·뛰기 선택→마지막 의뢰 편지까지 실행했다. 새 페이지로 이동한 뒤에도 발견 기록과 진행 위치가 복구되는 것을 확인했다.

## 검증 결과

- `npm test`: 204개 통과. 발견 팝업은 수첩에 붙이기 전에는 기록하지 않는 조건, 중복 방지, 근거 판정, 입력과 포커스, 정규화와 저장 복구, 실제 관찰에 따른 일기, HTML 이스케이프, 기존 완료 흐름을 포함한다.
- `npm run check`: 통과. `npm run build`: 204 runtime files, 120.11 MiB. `git diff --check`: 통과.
- 브라우저에서 1280×720, 1024×768, 768×1024를 확인했다. 긴 수첩과 일기는 스크롤하며 가로 넘침이 없다. 물리 태블릿의 터치 감도와 교실 학습자 사용성은 별도 검증하지 않았다.
- 임시 상태는 별도 localhost 49174에서만 사용했다. 실제 4173의 학생 기록에 테스트 정답을 쓰지 않았다. 임시 HTML/JSON은 제거하고 실제 로컬은 학생 기록을 보존하는 교사용 미리보기로 남겼다.
