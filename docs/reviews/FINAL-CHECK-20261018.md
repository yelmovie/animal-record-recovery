## 이번에 수정한 여섯 항목

1. 작품별 초안/완료본 분리: 오리발·안전모·외투의 설명과 시험 기록을 독립 보존. 과거 저장에서 이미 덮어써진 글은 복구할 수 없다.
2. 화면 배치: 1024×768, 1180×757, 1280×800, 1366×768에서 핵심 활동·패널의 내부 스크롤/44px 하한 점검. 재시험 결과 표와 이유·선택·하단 버튼 겹침 수정.
3. 비교 카드: 맞는 두 장만 놓고 틀린 카드는 남긴다는 안내, 드래그/탭/되돌리기 안내 표시.
4. 움직임: 동물별 실제 동작 시점에 맞게 목표 장면을 분산. 예상과 관찰 기록 추가, 예상 오답에 벌점 없음. 낙타·펭귄 5초 영상과 선택 관찰 추가.
5. 진행: 활동 완료 즉시 별 반영, 완료 장소 재입장 시 활동 선택 표시. 같은 활동에서 중복 별 없음.
6. 문장·TXT: 한글 조사 처리, 동물+부위+관찰 사실, 작품별 시험 조건·실패·비교 결과·설명 내보내기. UI와 TXT의 소감 선택값 일치 수정.

분류 반복 축소 요청을 반영한 현재 구성은 **5장 18활동**이다. 비교·환경·생활용품 설계 목표는 유지했다. 낙타·펭귄 선택 관찰은 필수 별 수를 늘리지 않는다.

## 실행 검증과 증거

- `npm run check` PASS, `npm test` **110/110 PASS**, `npm run build` **130 runtime files / 113.48MiB PASS**. 독립 lint/typecheck 스크립트와 TypeScript는 없음(N/A). 로그: `ux-regression-output.txt`.
- 실제 UI: 18개 탐구 활동을 단계별로 조작. 4장은 별도 빈 QA 기록에서 네 활동을 연속 완료(`stage4-four-activities.txt`). 완성 경로에서 18별·10의뢰, 아웃트로 종료→전시관 자동 이동 확인(`outro-to-gallery.png`).
- 세 발명 각각 실패 1회→수정→두 조건 성공, **총 3회씩**. 외투→안전모→외투 전환, 새로고침, 인증서의 개별 설명/시험 수 확인(`helmet-independent-trials.png`, `coat-preserved-before-helmet.png`).
- 실제 TXT 다운로드 성공. `actual-ui-research-record.txt`와 `downloaded-research-record.txt`는 UTF-8 BOM을 제외한 3,533자 내용 일치. 총 시험 9회, 작품별 실패 1회. 회상 선택 문구도 UI와 일치.
- 네 크기의 활동/탭 35상태씩 140상태: `ux-sizes-1024.json`, `ux-sizes-other.json`. 패널 scrollHeight≤clientHeight+2, 관측 버튼 44px 이상. 모든 픽셀·모든 모달의 전수 검사는 아님.
- 2행 재시험 표의 네 크기 실측: `retest-sizes.json`. 3행 표 추가 확인은 실제 **1366×768 한 크기**에서만 유효(`retest-three-sizes.json`); 재설정 시 화면 크기가 유지되어 다른 크기로 확장 주장하지 않음. 잘못된 요청 폭 이름의 중복 PNG는 제거하고 `retest-three-1366.png`만 보관했다.
- 영상: 낙타 걸음, 펭귄 수중 날갯짓 포착·저속 재생·기록 확인(`camel-motion-1180.png`, `penguin-motion-1180.png`). 24초 이야기 영상은 넘기기·재보기·아웃트로 종료 이동 확인. 화면별 이야기 버튼은 앞선 점검에서 48px 이상.
- 로컬 시작 계측: `loading-local.json`. 폰트 실측: `font-sizes.json`. 최종 배포본 탭 콘솔 수집 오류·경고 0(네트워크 전수 감사나 장시간 안정성 보장은 아님).

| 11 | 10→11 | 안내 상자를 실제 내용 길이에 맞춰 축소 | 빈 공간·캐릭터 가림; 최소/최대 글 길이 비교 |
| 12 | 7→11 | **2단계 우선:** 큰 화면에서 본문·버튼 20px+, 제목 30px+, 보조 16px 이상 자동 확대 | 한 화면 조작과 충돌 가능; 네 크기+1920 화면, 교실 뒷자리 판독 |
| 13 | 8→11 | 버튼 48px 권장 확대, 실기기 회전·터치·펜·IME 확인 | 태블릿 공간 감소; 세로 전환 안내와 복원 점검 |
| 14 | 9→11 | Safari/Chrome 실기기 및 영상 실패 대체·재시도 확인 | 자동재생/전체화면 정책 차이; 8동물+이야기 실제 재생 |

| 17 | 8→11 | **3단계:** 학교망 cold-load FCP/LCP·전송량 측정 후 필요한 에셋만 지연 로딩 | 로딩 순서 변경 위험; 측정값으로 최적화 전후 비교 |
| 18 | 9→11 | 대형 GLB/텍스처의 품질별 경량본, 미사용 기록 명확화 | 동물 특징 훼손 금지; 동일 관찰점 시각 비교 |

우선순위는 21(납품 규격)·12(가독성)·13/19(실기기·학교망)이다. 2단계는 가독성과 조작 영역을 함께 검증하고, 3단계는 측정 후 경량화하며, 4단계는 권리·호스팅 조건 확정 뒤 배포 검증한다.

## 미검증과 한계

실제 학생·교사 검수, 교실 뒤쪽 판독, 물리적 터치·펜·한글 IME, Safari, 학교망/완전 오프라인, 장시간 FPS·메모리, 전체 외부 통신, 운영 URL·하위 경로·공개 접근, 제공 자산 계약 범위는 이번에 확인하지 못했다. 브라우저 도구의 화면 크기 변경이 마지막 추가 점검에서 적용되지 않은 결과는 실제 크기 그대로 보고했다. 로컬 테스트 성공을 운영 배포 성공으로 간주하지 않는다.
