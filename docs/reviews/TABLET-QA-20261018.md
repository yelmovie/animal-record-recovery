# 태블릿 화면 통합 점검 · 2026-10-18

## 적용

- 기존 main 작업 폴더에서 앞선 전시관/의뢰 작업과 8종 GLB 교체를 유지했다. 별도 브랜치 병합, 커밋, 배포는 하지 않았다.
- 상단 아이콘 한 줄, 왼쪽 모리 안내, 활동 영역과 최소 이동 버튼. 긴 기록은 탭으로 전환한다.
- 분류 탐색은 4개에서 2개로 축소, 전체 탐색 별은 18개. 이전 저장 기록을 새 구조로 복원한다. 분류 칸은 O/X로 표시한다.
- 첫 화면 탐험가는 기존 남자아이 외형으로 교체. 생태돔에 이미지 재질을 적용했다.
- 공방의 제품 3종·부품 3종·특징 3종을 이미지로 교체하고, 이미지 영역을 명시적으로 잘라 옆 그림 노출을 막았다. 밝은 판 위에 분리해 보여 주며 부품의 사각 배경이 원래 제품을 가리지 않게 처리했다.
- 관찰·생태돔은 실제 GLB 준비 전 로딩 안내만 표시한다. 임시 도형 동물을 먼저 표시하지 않는다. 실패 시 기존 2D 학습 화면으로 전환한다.

## 확인

- `npm run check`, `npm test`: 93개 통과. `npm run build`: 96개 파일, 약 55.73 MiB.
- 1024×768, 1280×800, 1920×1080: 18개 기본 활동 × 3크기 = 54회 DOM 넘침 점검. 본문·활동·왼쪽 안내 영역 모두 가로/세로 넘침 0.
- 1024×768: 지도·홈·전시관·보상·결과·5개 장의 첫 의뢰 확인. 최종 의뢰의 시험/결과를 탭으로, 결과 화면의 두 발명을 탭으로 분리한 뒤 의뢰와 인증서 영역 넘침 0 확인.
- 새 기록에서 문제 선택 → 부품 선택 → 발끝 배치 확인. 탭을 전환해도 선택·배치 유지. 특징 확대 팝업 정상.
- 개구리 3D 확대·회전, 오리 실제 모델 표시 확인. 오리 로딩 중 `aria-busy=true`, canvas `visibility:hidden`을 확인하고 준비 후 실제 GLB 표시 확인. 생태돔도 모든 동물 준비 후 표시 확인.
- 증빙: `workshop-clean-1024.png`, `landing-boy-1280.png`, `model-loading-clean.png`, `dome-ready-1280.png`.

## 범위와 남은 항목

- 가로 태블릿을 주 검증 대상으로 삼았다. 짧은 휴대폰/세로 화면은 별도 반응형 규칙과 내부 스크롤을 허용하며 이번 전체 순회 검증 대상에는 포함하지 않았다.
- 모든 오답 조합·긴 사용자 입력·센서 기울이기·실물 태블릿의 두 손가락 제스처는 이번에 전수 검증하지 않았다.
- 동물 영상 6편은 아직 생성/연결하지 않았다. `../MOTION-VIDEO-PROMPTS.md`에 기존 외형 참고, 초기 이미지 프롬프트, 5초 영상 프롬프트를 제공한다. 현재 움직임 기록은 기존 3장면 설명 모형이다.
- 이전 delivery ZIP은 이번 수정으로 다시 만들지 않았다. 현재 빌드 결과는 `dist/`다.
