# 카드·글자·패널 균형 개선 · 2026-10-23

공통 스타일 `src/responsive.css`에서 카드와 선택지의 글자·폭·높이·간격을 조정했다. 학습 문제, 정답, 진행 상태, 저장 형식, 마을 이동 방식은 수정하지 않았다.

- 핵심 선택지: 22–32px, 증거·비교 카드 문장: 24–36px. 문장과 보조 분류 이름의 크기를 구분하고, 한글은 어절 단위로 감싸도록 했다.
- 생활 연결: 세 연결 칸이 남은 화면 높이를 채우지 않도록 했다. 증거 카드는 문장 길이에 맞는 폭으로 세 열에 모으고, 낮은 가로 화면에서는 연결 칸과 증거 카드를 좌우에 배치한다.
- 예시 1920×1000: 연결 칸 묶음 높이 약 445→139px, 증거 카드 패널 폭 약 1890→925px, 카드 본문 약 27→35px.
- 관찰·비교·분류·검증·발명: 선택 카드의 불필요한 가로 늘리기를 줄였다. 큰 화면의 비교·검증·시험 패널은 읽기 편한 폭 안에 모으고, 배경은 전체 화면을 유지한다.
- 일반 의뢰: 질문에 더 많은 폭을 주고, 큰 장식 프레임은 내용 높이에 맞는 요약 카드로 정리했다. 요약 제목과 동물·기록을 자연스럽게 배치하고 보조 문장도 읽을 수 있게 했다.
- 방송 의뢰: 넓은 화면의 세 선택지를 한 줄에 배치하고, 좁은 화면에서는 문장 폭에 맞게 감싼다. 이전 스타일의 강제 열 수·마지막 카드 열 병합과 충돌하는 규칙도 정리했다.
- 전시관: 설명 글을 키우고 전시 이미지 높이가 유지되는지 확인했다.
