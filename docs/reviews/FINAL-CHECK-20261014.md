## 최종 판정: 조건부 배포 가능

## 총점: 185/220 · 측정 범위 20/21 · 11점 0개 · 10점 9개

작성: 2026-10-14. 실행한 항목과 미확인 항목을 구분한 기술 검수 결과이며 학생의 실제 학습효과를 입증하는 실험 결과는 아니다. 영상 항목 14는 N/A로 분모에서 제외했다. 11점 초과 조건은 별도 입증하지 않아 부여하지 않았다. 이전 동일 기준 점수는 없다.

## 실행 증거

- `npm run check`: 통과. JS와 빌드 스크립트 구문 검사. 별도 lint/TypeScript 없음(N/A).
- `npm test`: 23/23. 전체 단계 조건, 틀린 근거, 세 발명, 오래된 시험 결과, 손상 저장, 관리자 모드, 내비 초기화, 저장 실패, 악성 문자, 잘못된 구조 ID, 시험 이력 수정 방향 검증.
- `npm run build`: 26 runtime files, 약 4.73 MiB. 빌드 매니페스트 포함.
- 빌드 서버 127.0.0.1:4174: 26자원 모두 200, WebP MIME 정상, 비공개 package.json 404. 첫 화면 필요 자원 합계 854,377 bytes. 로컬 순차 HTTP 27ms는 전송 진단값일 뿐 브라우저 로딩 시간으로 사용하지 않았다.
- 브라우저 원본 서버: 1장~5장 완료, 부족한 관찰·모호한 기준·부족한 추리 근거·잘못된 발명 구조의 실패와 재시도, 인증서와 TXT 내용 확인.
- 브라우저 배포 서버: 새 탐험→관찰 1개→새로고침→1/6 복원; 관리자 해금→외투 설계; 펜 드래그 1개→새로고침 후 SVG 선 1개 복원; 확인 후 초기화→0/5·뒤로가기 비활성화.
- 오류/경고 로그: 점검 시 0건. 전수 네트워크 trace 또는 장시간 메모리/FPS 검사는 수행하지 않음.
- 1280×800, 1920×1080, 1024×768, 915×412, 375×812, 768×1024, 1440×900 대표 화면 확인. 작은 높이는 세로 스크롤을 사용한다. 전 화면×전 해상도 조합 전수 검사는 아님.
- 스크린샷: `screenshots/`의 home, observation, design, ending 파일. 초기 확인 이미지와 최종 배포본 이미지가 섞여 있으므로 UI 증거로 사용하며 픽셀 회귀 기준은 아니다.

## 수정한 주요 문제

1. 관찰·제품·생태 요소에 실제 이미지 적용, 정체를 미리 보여 주던 추리 그림 교체.
2. 캐릭터 잘림, 모바일 시작 버튼과 캐릭터 겹침, 페이지 이동 후 스크롤 잔류 수정.
3. 초기화 이후 완료 경로 재진입 차단, 저장 실패 즉시 안내·재성공 시 해제.
4. prototype 이름 형태의 손상 저장값으로 발명 화면이 멈추는 문제 수정.
5. 시험 이력에서 선택 문자열을 boolean 결과로 착각하던 오류 수정.
6. 배포 시 CSS 변수의 상대 이미지 URL이 src/assets로 잘못 해석되던 문제를 모듈 기준 절대 URL 생성으로 수정.

## 개선 우선순위와 11점 재검증

- **21번 7→11:** 필수—권리 주체·운영 배포 조건 확정 후 운영 smoke test. 추천—납품 플랫폼 양식에 출처·제작 정보를 맞춤. 위험—확정되지 않은 이용 허락을 문서가 대신 부여하면 안 됨.
- **19번 8→11:** 필수—학교망/오프라인 테스트. 추천—오프라인이 실제 요구사항이면 필요한 자원 캐시 설계. 위험—서비스워커 업데이트와 저장 복원 정책을 함께 검증해야 함.
- **20번 8→11:** 필수—권리 확인과 실제 네트워크 trace. 추천—운영 CSP/캐시 헤더 점검. 위험—개발 서버 검증을 운영 안전성 보증으로 확대하지 않음.
- 나머지 9점 항목은 표의 미확인 사항을 실제 기기·학생·교사·브라우저 계측으로 검증해야 점수를 올릴 수 있다. 10점 항목의 11점 조건은 별도 개선/측정 범위이며 이번에 추정으로 올리지 않았다.
