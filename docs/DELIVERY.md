# 전달 안내 · 0.5.0

## 실행

Node.js 20 이상. 실행에 외부 패키지 설치나 API 키가 필요하지 않다.

```sh
npm run check
npm test
npm run build
npm run preview
```

기본 미리보기는 `http://127.0.0.1:4173`. 이미 사용 중이면 PowerShell에서 `$env:PORT='4179'; npm run preview`로 다른 포트를 사용한다. `file://` 더블클릭은 ES 모듈 때문에 지원하지 않는다.

## 포함 내용

- `dist/`: 130개 실행 파일과 빌드 매니페스트, 약 113.48 MiB.
- `delivery/animal-record-recovery-web-0.5.0.zip`: 이전 작업의 ZIP으로 이번 최종 소스와 일치하지 않는다. 현재 전달본은 최신 `dist/`를 사용한다.
- 원본 프로젝트: 소스·생성 프롬프트·테스트·문서를 D: 폴더에 보관한다. 이전 미사용 이미지·GLB는 용량 정리 요청으로 삭제했으며, 이번 나비 원본은 모델 원본 폴더에 한 부 보관한다.
- 검증: `docs/reviews/FINAL-CHECK-20261018.md`.
- 10월 18일 새 3D 모델 8종 적용: `docs/MODELS-20261018.md` (이후 모델 교체 빌드·용량은 이 문서 기준).
- 설계: `docs/MUSEUM-PLAN-20261018.md`.

분류 반복을 줄인 탐색 18개·3D 표본·생태 돔·비교 시험을 유지하고, 의뢰 10개·선택 도전 5개·주민 답장·개인 전시관을 추가했다. PNG 원본·문서·테스트·검증용 서버는 배포 파일에 포함하지 않는다.

## 저장과 배포 상태

기록은 현재 브라우저의 LocalStorage에만 저장한다. 주소·포트·브라우저가 달라지면 별도 기록이다. 이전 완료 장소·도구·별을 유지하고, 추가 의뢰 완료를 자동으로 부여하지 않는다. 제출한 전시 기록은 수정 중인 초안과 분리해 보관한다.

기존 공개 주소는 0.4 배포를 유지했다. 이번 0.5 변경은 로컬 구현·검증과 배포 파일 준비까지 완료했다. 공개 배포 시 `dist/` 내용만 사용한다. 현재 Cloudflare 설정은 `wrangler.jsonc`에 있다.

실제 학생·교사 검토 및 실제 Safari/Chrome 태블릿·전자칠판·학교 네트워크 확인은 별도다. 새 저장·모바일 화면 검증 범위와 한계는 QA 문서에 기록했다.
