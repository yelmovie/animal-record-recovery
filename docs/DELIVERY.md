# 전달 안내 · 0.5.0 (2026-10-21 갱신)

## 실행

Node.js 20 이상. 실행에 외부 패키지 설치나 API 키가 필요하지 않다.

```sh
npm run check
npm test
npm run build
npm run preview
```

기본 미리보기는 `http://127.0.0.1:4173`. 이미 사용 중이면 PowerShell에서 `$env:PORT='4179'; npm run preview`로 다른 포트를 사용한다. `file://` 더블클릭은 ES 모듈 때문에 지원하지 않는다.

## 포함 내용

- 탐색 18개(1~5장), 주민 의뢰 10개(장소마다 2개)와 선택 도전 5개, 자유 발명 그림·작품 소개, 엔딩 영상, 인증서, 개인 전시관, 연구 기록 TXT·작품 PNG 저장.
- `dist/`: `npm run build` 결과 197개 실행 파일, 약 119.75 MiB(2026-10-21 로컬 빌드). 공개 배포 시 `dist/` 내용만 올린다.
- `delivery/*.zip`: 이전 작업의 묶음이며 현재 소스와 일치하지 않는다. 납품 묶음이 필요하면 최신 `dist/`로 다시 만든다.
- 이번 수정 내용·검증 범위: `docs/reviews/LEARNER-CLARITY-20261021.md`. 이전 종합 점검: `docs/reviews/FINAL-CHECK-20261020.md`.

공개 주소 `https://animal-record-recovery.yelsam.workers.dev`는 이번 변경 전 배포본이다. 2026-10-21 수정은 로컬 구현·테스트·빌드까지 했고 **운영 배포는 하지 않았다.** 배포는 `npm run deploy`(빌드 후 `wrangler deploy`)로 한다.

## 공용 태블릿 기록 보관·초기화

기록은 그 기기의 그 브라우저 LocalStorage에만 저장된다. 학생 이름·학번을 받지 않고 서버로 보내지 않는다. 주소·브라우저·기기가 바뀌면 이어지지 않는다.

1. 보관: ‘내 전시관’ → **내 전시 기록 저장**(또는 인증서 → **나의 연구 기록 저장**)으로 TXT, 그림판 **작품 저장**(또는 인증서 → **작품 이미지 저장**)으로 PNG를 받는다. 기기의 다운로드 폴더에서 교사가 수합한다.
2. 초기화: 설정 → **탐험 기록 초기화** → 확인. 별·장소·관찰·그림·글이 모두 지워지고 되돌릴 수 없다. 소리 설정은 남는다.
3. 브라우저 사이트 데이터 삭제도 기록을 지운다. 교사용 **전체 단계 해금**은 시연용이며 학생 기록을 바꾸지 않는다.

이전 저장과의 호환: 2026-10-21에 관찰 문제별 ‘처음 정답/도움 후 정답’ 필드를 더했다. 저장 형식 번호는 그대로이고, 이 필드가 없는 이전 기록은 진도·그림·글을 그대로 열고 해당 관찰만 ‘모름’으로 센다.
