# 납품 안내 · 0.3.0

## 실행·검증

Node.js 20 이상. 외부 패키지 설치 및 API 키 불필요.

```sh
npm run check
npm test
npm run build
npm run preview
```

`npm run preview`는 `dist/`를 127.0.0.1:4173에서 제공한다. 4173이 사용 중이면 PowerShell에서 `$env:PORT='4174'; npm run preview`로 별도 포트를 쓸 수 있다. 파일을 더블클릭하는 file:// 방식은 ES 모듈 때문에 지원하지 않는다.

## 전달물

- `delivery/animal-record-recovery-web-0.3.0.zip`: 정적 호스팅에 올릴 런타임 파일. 압축을 풀면 index.html이 최상위.
- `dist/`: 동일한 빌드 결과. PNG 원본, 문서, 테스트, 개발 스크립트를 제외한 WebP 포함 32개 실행 파일과 매니페스트.
- 프로젝트 원본 폴더: 편집 가능한 소스·이미지 원본·프롬프트·테스트·설계·검수 보고서. 모두 기존 D: 프로젝트에 보존.

WebP 포함 전체 런타임 약 5.07 MiB. 기존 생성 이미지 11종과 새 탐험 이미지 7종의 PNG 원본은 D: 프로젝트에 보존한다. 20개 활동, 인간 탐험가 하루와 보조원 모리, 길을 따라 이동하는 지도, 실제 기록을 보여 주는 보상 도구가 포함된다. 검증 결과는 `docs/reviews/ADVENTURE-QA-20261015.md`에서 확인한다.

## 배포

정적 호스팅에 `dist/` 내용만 업로드한다. 이미지 경로는 모듈 URL과 CSS 상대 경로를 사용하므로 하위 디렉터리에 대응하는 구조다. 최종 호스팅의 base path·캐시·HTTPS에서 실제 확인은 아직 하지 않았다. 개발 서버는 로컬 검토 전용이며 외부에 공개하지 않는다.

저장은 브라우저 LocalStorage이며 주소·포트가 바뀌면 별도 기록이다. 서버로 개인정보를 전송하지 않는다. 공용 태블릿에서는 수업 후 연구도감에서 확인 단계를 거쳐 초기화한다. 관리자 전체 해금은 수업용 편의 설정이며 접근 보안 기능이 아니다.

## 납품 전 남은 확인

1. 발주 측: 기존 제공 이미지의 권리, 저작권 표시 주체·배포 플랫폼·계약 범위 확정.
2. 담당 교사: AI 동물 그림과 과학 설명, 학교 수업에 맞는 학년·성취기준 및 실제 학생 사용성 검수.
3. 배포 담당: 실제 Safari/Chrome 태블릿·전자칠판, 약한 학교 네트워크, 운영 URL 저장·새로고침·다운로드 점검.

오프라인 전체 진행은 보장하지 않는다. 처음 방문하지 않은 장의 이미지는 연결이 필요하다. 사용자 요구 범위에 따라 서비스워커나 외부 백엔드는 추가하지 않았다.
